# U-Bahn Anzeige auf dem iPad

Diese Version braucht **keinen Computer und kein Python** – sie holt die Echtzeitdaten
direkt von der MVG und läuft in Safari, auch auf älteren iPads.

## Einmalig online stellen (GitHub Pages, kostenlos)
1. Pull Request auf GitHub übernehmen („Merge pull request“).
2. Im Repository: **Settings → Pages → Build and deployment → Source: „Deploy from a branch“**,
   Branch **main**, Ordner **/(root)** → **Save**.
3. Nach 1–2 Minuten ist die Anzeige erreichbar unter:
   **https://josefko85.github.io/Josef-Kozumplik/ipad/**

## Auf dem iPad
1. Die Adresse oben in **Safari** öffnen.
2. **Teilen-Symbol → „Zum Home-Bildschirm“** → Hinzufügen. Jetzt gibt es ein U-Bahn-Symbol wie bei einer App,
   und die Tafel startet ohne Safari-Leisten.
3. iPad quer hinstellen (dann mit Bahnhofsuhr).
4. Damit der Bildschirm anbleibt: **Einstellungen → Anzeige & Helligkeit → Automatische Sperre → Nie**
   (Ladekabel anschließen).
5. Optional „Geführter Zugriff“ (Einstellungen → Bedienungshilfen), damit die Tafel immer offen bleibt.

Einstellungen per Adresse, z. B. `…/ipad/?richtung=alle` oder `…/ipad/?station=Odeonsplatz&zeilen=5`.
