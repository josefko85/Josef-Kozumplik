# GastrokasseApp Beispiel

Dieses Repository enthält ein einfaches SwiftUI-Beispiel für eine Gastronomie-Kassenanwendung.
Die wichtigsten Dateien befinden sich im Ordner `GastrokasseApp`:

- `GastrokasseApp.swift` startet die App.
- `ContentView.swift` zeigt eine Liste von Artikeln und ermöglicht das Hinzufügen zur Bestellung.

Um das Beispiel in Xcode zu verwenden, kann man ein neues "SwiftUI App"-Projekt erstellen und diese Dateien ersetzen.
